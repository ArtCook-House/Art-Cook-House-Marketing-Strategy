# ArtCook House Marketing Strategy
 مشروع تطوير الاستراتيجية الرقمية لمركز آرت كوك هاوس لتعليم الطهي.
 
فريق العمل والمدرب: ذكر أسماء الأعضاء الستة (ماجد، عمر، كريستينا، ريهام، سلمى) تحت إشراف الأستاذ "أشرف روبي".


نطاق المشروع (Project Scope): توضيح الأهداف التسويقية، المخرجات مثل "تحليل المنافسين" و"الهوية البصرية"، والمتطلبات الحالية.

الأهداف الاستراتيجية: تعزيز التواجد الرقمي، تحسين SEO، وزيادة معدلات التحويل والاشتراك.
