# 🍳 Art Cook House - Digital Marketing Strategy
### مشروع مبادرة مصر الرقمية (DEI)

## 📌 نظرة عامة على المشروع
**Art Cook House**
---
هو مركز متخصص في تقديم دورات طهي احترافية في منطقة مصر الجديدة. يهدف هذا المشروع إلى تطوير الإستراتيجية الرقمية وبناء محتوى إبداعي يحول المنصات الاجتماعية (فيسبوك، إنستجرام، يوتيوب، وتيك توك) إلى واجهة جذابة تليق بمستوى الكورسات وتساهم في زيادة قاعدة العملاء والاشتراكات.

## 🎯 أهداف المشروع
* تعزيز التواجد الرقمي عبر استراتيجية متكاملة تشمل تطوير المحتوى البصري والنصي.
* تحسين الظهور في محركات البحث (SEO) لسهولة الوصول للمركز.
* زيادة الوعي بالعلامة التجارية والوصول بدقة للجمهور المستهدف.
* رفع معدلات التحويل والاشتراك الفعلي في الكورسات التدريبية.

---

## 📦 نطاق المشروع (Project Scope)
1. **الأهداف:** تحسين المستوى التسويقي للصفحات وزيادة أعداد المتابعين والمشتركين بالخدمة.
2. **المخرجات:** الوصول لخطة تسويقية شاملة، تحليل المنافسين، هوية بصرية مطورة، وصفحة احترافية لعرض الكورسات.
3. **المتطلبات:** المنصات القائمة حالياً، المتخصصين في الطبخ، وميزانية الإعلانات المحددة.
4. **القيود:** الالتزام بالجدول الزمني (5 أسابيع) والميزانية المتوفرة.

---

## 📅 خطة العمل (Roadmap)
| الأسبوع | التركيز الأساسي | المهام الرئيسية |
| :--- | :--- | :--- |
| **الأسبوع 1** | التأسيس والهوية | تحديد الجمهور بدقة، تحويل الحسابات لنظام Business، وبدء المحتوى الأولي. |
| **الأسبوع 2** | المحتوى التعليمي | صناعة فيديوهات قصيرة (Reels) والتركيز على زيادة التفاعل مع المتابعين. |
| **الأسبوع 3** | الحملات الإعلانية | إطلاق الإعلانات الممولة، تقديم العروض، ونشر فيديوهات "كواليس العمل". |
| **الأسبوع 4** | المصداقية والنتائج | عرض آراء العملاء (Testimonials) وإبراز جودة التجهيزات والتحضيرات. |
| **الأسبوع 5** | التغطية والتوثيق | استعراض تجارب المشتركين وتغطية شاملة للكورس لتوثيق النجاح. |
